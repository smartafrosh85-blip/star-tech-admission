# STAR TECH Admission

Simple static site for STAR🌟TECH admissions.

## Setup
- This site is pure HTML/CSS/JS and can be hosted on GitHub Pages.

## Form notifications
- The application form posts to Formspree. Replace the form endpoint in `script.js` if needed.

## Deploy (example)
```bash
git init
git add .
git commit -m "Initial site"
git branch -M main
git remote add origin https://github.com/smartafrosh85-blip/star-tech-admission
git push -u origin main
```
